# 验证边界

公开版验证使用合成数据，不连接任何真实公司系统。

- 三行离线示例覆盖长 ID、账号前导零、全零行、重复 ID、附加指标移除，以及本地交付副本的 SHA256。
- 自动测试检查跨月、跨年、闰年、数据和字体篡改、空表、错日期、缺列、重复列、公式与不安全数值 ID。
- 交付测试使用内存存储代替外部服务，检查完成状态、旧修改时间、重复调用和结果不确定时停止。
- 协议测试替换 HTTP 边界，检查 File Station 登录、分页查询、multipart 请求参数及 SSL 错误脱敏。
- GitHub Actions 在 Python 3.11 和 3.13 上运行测试及演示；绿色状态以对应提交的实际运行结果为准。

原始私有流程曾在数万行级文件上完成全量核验并通过公司盘接口上传。它也发生过网页勾选超时和 SSL 连接失败。这里仅总结经验，不上传原文件、原日志、账号、组织标识或内部地址。公开版做了可移植重构，旧流程成功记录不能替代公开版的真实 NAS 联调。

当前仍需由实际使用者验证：自己服务器的 API 版本、账号权限、证书链、目标目录，以及后台报表筛选口径。长时间稳定性和真实吞吐量未由本仓库的三行演示证明。
